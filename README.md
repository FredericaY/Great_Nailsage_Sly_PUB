# Great Nailsage Sly

一个基于 Unity 开发的 2D 动作游戏项目，核心体验围绕角色移动、近战攻击、敌人 AI、Boss 遭遇战与成长系统展开。项目以横版动作玩法为基础，在实现角色手感与战斗反馈的同时，也搭建了较完整的客户端侧系统模块，包括背包、商店、对象池、行为树、音频服务、场景切换与事件时序控制等。

## 项目简介

- 项目类型：Unity 2D 动作游戏
- 引擎版本：Unity `2022.3.62f3`
- 渲染管线：URP
- 输入方案：Unity Input System
- 主要场景：`Assets/Game/Scenes/Levels/All_Levels.unity`
- 当前定位：以玩法原型和系统搭建为主，覆盖角色、敌人、UI、交互与关卡内核心循环

## 核心功能

### 1. 角色动作与战斗

- 实现了横版 2D 动作游戏常见的移动、跳跃、贴墙、受击、攻击等基础能力。
- 角色模块以 `PlayerRoot` 为入口，对输入、移动、朝向、攻击、动画、传感器和能力系统进行统一组织。
- 战斗表现包含攻击判定、受击反馈、镜头震动、受伤闪白、血量变化与掉落物生成。

### 2. 背包与能力系统

- 项目实现了护符背包系统，支持已拥有护符管理、装备切换、默认初始状态配置等功能。
- `PlayerCharmInventory` 负责背包数据与事件分发，通过 `OnInventoryChanged`、`OnCharmAdded`、`OnEquippedCharmChanged` 驱动 UI 与运行时逻辑同步。
- `PlayerCharmRuntime` 将装备结果映射为角色运行时能力，使“数据配置”和“能力生效”解耦。

### 3. 商店系统

- 项目内置可交互商店区域，玩家靠近后可打开护符商店并使用货币购买内容。
- `CharmVendor` 同时处理交互触发、玩家锁定、UI 面板创建、时间暂停、购买校验与结果反馈，形成完整交易闭环。
- 商店支持排除指定物品、已拥有状态判断、价格校验、消耗品与永久能力区分等逻辑。

### 4. 对象池与复用机制

- `ProjectilePoolService` 为弹体类对象提供场景级共享池，支持预热、生成、延迟回收、运行时状态重置等能力。
- 音频层的 `AudioService` 也采用池化思路管理 SFX Voice，减少高频播放场景下的临时对象创建与销毁。
- 这类复用机制主要用于降低运行时抖动，提升战斗密集场景下的稳定性。

### 5. 敌人 AI 与行为树

- 敌人侧通过 `EnemyRoot` 聚合黑板、生命、受击、死亡、动画、移动范围与行为树组件。
- 项目接入 `Behavior Designer`，将敌人决策逻辑与表现逻辑拆分，便于配置巡逻、追击、攻击、转向、死亡等行为。
- 这种组织方式能让 AI 行为扩展更偏配置化，适合在后续持续添加敌人种类与 Boss 行为。

### 6. 遭遇战与时序控制

- `EnemyEncounter` 负责遭遇触发、Boss 生成、玩家输入锁定、标题展示、镜头震动和击败回调等流程。
- 项目大量使用协程驱动短时序逻辑，如 Boss 开场、深渊/危险区域处理、受击闪烁、音频淡入淡出、延迟回收等。
- 通过将一次交互拆成可维护的阶段流程，项目在玩法表现层和系统逻辑层之间建立了比较清晰的时序控制方式。

## 架构设计

### 总体思路

项目整体采用“实体根节点 + 模块组件 + 系统服务”的组织方式：

- 实体层：`PlayerRoot`、`EnemyRoot` 作为角色与敌人的结构入口，统一暴露模块引用。
- 模块层：移动、战斗、动画、背包、货币、交互、传感器等能力通过独立组件拆分。
- 系统层：对象池、音频、场景切换、商店、危险区、能力系统等作为可复用服务存在。
- 表现层：UI、动画、音效、镜头震动、受击特效负责将玩法反馈可视化。

### 架构特点

- 低耦合：运行时能力、UI 展示、交互逻辑通过事件或引用聚合进行连接，而不是硬编码耦死。
- 可扩展：新增角色能力、护符、敌人或关卡交互时，通常可以在现有模块基础上扩展，而不需要大幅改动主流程。
- 易维护：`Root` 类承担“结构汇总”职责，业务逻辑仍然保留在具体模块内部，便于排查和迭代。
- 面向玩法迭代：诸如行为树、对象池、协程序列、场景音频服务，都是为后续内容扩展预先搭好的基础设施。

## 目录结构

```text
Assets/Game
├─ Scenes/                # 关卡与启动场景
├─ Scripts/
│  ├─ Audio/              # 音频服务、场景音频配置
│  ├─ Combat/             # 攻击、投射物、对象池
│  ├─ Core/               # 核心输入与基础能力
│  ├─ Enemies/            # 敌人、Boss、遭遇战、AI
│  ├─ Player/             # 玩家主体与动作/战斗模块
│  ├─ Systems/            # 护符、商店、场景、危险区等系统
│  ├─ UI/                 # HUD、暂停菜单、Boss 血条等界面
│  └─ Utils/              # 协程、相机震动、传感器等通用工具
├─ Prefabs/               # 角色、敌人、特效、环境预制体
├─ Animation/             # 玩家、敌人、特效动画资源
├─ Audio/                 # 音频资源与配置
└─ Art/                   # 美术资源
```

## 运行方式

1. 使用 Unity Hub 打开项目。
2. 选择 Unity `2022.3.62f3` 版本进入工程。
3. 等待依赖导入完成。
4. 打开 `Assets/Game/Scenes/Levels/All_Levels.unity` 运行项目。

如果需要检查项目初始化流程，也可以查看 `Assets/Game/Scenes/_Bootstrap/Bootstrap.unity`。

## 项目亮点

- 不只是完成基础玩法原型，还搭建了面向持续迭代的客户端系统骨架。
- 将玩法逻辑、运行时数据、UI 反馈和表现层拆分开，便于后续扩展与调试。
- 在动作游戏高频交互场景下，优先考虑了对象复用、流程编排与模块职责边界。
